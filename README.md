You can just execute <b>Grapyus.bat</b>, which will launch the script using the included python environment.

<h3>Controls</h3>
<b>WASD</b> to move </br>
<b>SPACE</b> to shoot </br>
<b>TAB</b> to pause/unpause the game</br>
