  I did this project at school while getting my vocational training in IT, to learn object oriented programming and hone my python skills, but mostly it was just a way to pass the time during boring classes.

  <h3>Installation</h3>
  <b>You do not need to have python installed.</b></br>
  Just download the .zip file of the latest release, unzip it somewhere, and run <b>Grapyus.bat</b>. A console window should open saying "GAME START" and the game window should pop up.</br>
  
  - If you open Grapyus.py with a text editor, you can set a custom resolution in the top section under "General Settings", but although all sizes should be relative to your screen size, movement might be different. The game is currently only optimized to run in a 720p window. You can only set 16:9 resolutions, because the game's internal size calculations depend heavily on that aspect ratio.</br>
  - Grapyus is specifically programmed for Windows, and it includes a portable python environment for Windows x64. It will not run on Linux or Mac without modifying Grapyus.py itself.

  <h3>Controls</h3>
    <b>WASD</b> to move </br>
    <b>SPACE</b> to shoot </br>
    <b>TAB</b> to pause/unpause the game</br>
